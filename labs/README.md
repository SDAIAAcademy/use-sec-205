# الذكاء الاصطناعي في التنقل والخدمات اللوجستية: المختبرات

أربعة مختبرات لمقرر أكاديمية سدايا **USE-SEC-205**، مدة كل منها 75 دقيقة، وعمل تحضيري متعقَّب قبل اليوم الأول. المختبرات
صفحات إرشادية بالعربية: الهدف، والملفات، وخطوات بدقائقها، وأسئلة تحقق، ومهمة إضافية ✱، وملاحظات للمدرّب. يعمل المشارك
في جدول بيانات إلكتروني ومستندات، ويشغّل في المختبر 1.1 دفترًا جاهزًا دون أن يكتب كودًا.

كل المختبرات في جهة واحدة: **شركة رَكْب للخدمات اللوجستية الحضرية**، شركة افتراضية. الطلبات والأسطول والحوادث والادعاءات
وحالات الاستخدام اصطناعية. المسافات من طرق OpenStreetMap الحقيقية (`files/routing/ATTRIBUTION.txt`)، وسجلات الرحلات
اليومية حقيقية من بوابة البيانات المفتوحة لمدينة شيكاغو (`files/forecast/ATTRIBUTION.txt`).

## ما يحتاجه المشارك

- جدول بيانات إلكتروني (Excel أو LibreOffice Calc أو Google Sheets). Orange Data Mining وKNIME بديلان لمن يفضّلهما.
- للمختبر 1.1: حساب Google لفتح الدفتر في Colab، أو بيئة Jupyter على الجهاز. الدفتر ينزّل أداة الحل (OR-Tools) وحده.
- لا نموذج ذكاء اصطناعي في أي خطوة. الخطوات 1 إلى 4 من المختبر 2.2 دون ذكاء اصطناعي. في المختبرات الأخرى يجوز مساعد
  عام بدور المعلّم، ولا يُرفع إليه ملف حقيقي عن سائق أو عميل.

## العمل التحضيري

نحو ساعتين قبل اليوم الأول: `files/prework/prework_guide.txt` و`files/prework/decision_card.xlsx`. بطاقة لقرار تخطيط أو
سلامة واحد وبياناته، يفتحها المدرّب قبل الجلسة الأولى، وتُستخدم في الخطوة الأولى من المختبر 1.1. من لا يعمل في جهة نقل
الآن يختار قرارًا من `files/prework/rakb_profile.txt`.

## نقطة البداية والحل

كل مختبر يبدأ من ملفات جاهزة ولا يعتمد على مختبر آخر. الخريطة (`files/map/map_template.xlsx`) تكبر بسطر في آخر كل
مختبر؛ من فاته مختبر يكتب سطره من بطاقة الحالة في `files/map/use_cases_14.txt`.

| المختبر | الصفحة | يبدأ من | الحل المرجعي |
|---|---|---|---|
| 1.1 | `D1_1_routing.html` | `routing/routing_lab.ipynb` وملفات `routing/`، و`prework/decision_card.xlsx` | `solutions/check.py 1.1`، `solutions/answer_key.md` |
| 1.2 | `D1_2_forecast.html` | `forecast/trips_daily.xlsx`، `forecast/mawsim_brochure.txt` | `solutions/check.py 1.2` |
| 2.1 | `D2_1_incidents.html` | `incidents/fleet_year_2025.xlsx`، `incidents/yaqiz_claim.txt`، `incidents/note_template.txt` | `solutions/check.py 2.1` |
| 2.2 | `D2_2_claims_and_map.html` | `claims/`، و`map/` | `solutions/check.py 2.2 map` |

## تشغيل الحلول

```bash
uv run labs/solutions/check.py            # كل المختبرات والخريطة
uv run labs/solutions/check.py 1.1 2.1    # بعضها
```

ملف واحد يعلن اعتمادياته (OR-Tools)، ويحتاج [uv](https://docs.astral.sh/uv/). يعيد حساب كل رقم في مفتاح الإجابات من
الملفات التي يتسلمها المشارك، ويشغّل أداة الحل من جديد ويتحقق أنها تعطي الخطة المرجعية، ويطبع `PASS` لكل مختبر. لا يكتب
شيئًا ولا يتصل بأي نموذج.

الدفتر نفسه يُشغَّل من مجلد `files/routing`:

```bash
cd labs/files/routing
uv run --python 3.13 --with ortools==9.14.6206 --with nbclient --with ipykernel jupyter execute routing_lab.ipynb
```

## الملفات

| الملف | ما هو | المزروع فيه |
|---|---|---|
| `routing/deliveries_120.csv` (و`.xlsx`) | 120 طلبًا على طرق الرياض، بالصناديق والنوافذ | 14 طلبًا مبرّدًا، و6 قطع أثاث، و18 برجًا: قواعد لا يقرؤها النموذج الأول |

| `routing/dispatcher_notes.txt` | قواعد المرسِل الأربع | الراحة قاعدة لا يعرفها النموذج حتى بعد المفاتيح |
| `forecast/trips_daily.csv` (و`.xlsx`) | 461 يومًا من رحلات شيكاغو، وتنبؤ «موسم» | تنبؤ بلا تقويم: ممتاز في الأيام العادية، سيئ في العطلات |
| `incidents/fleet_year_2025.csv` (و`.xlsx`) | 200 مركبة × 12 شهرًا | مستودع الأكثر عددًا والأقل معدلًا؛ كاميرات على أسوأ عشرين مركبة: ارتداد نحو المتوسط |
| `claims/claims_8.txt` | ثمانية ادعاءات أتمتة | اسم تجاري مضلل، و«ارفع يديك»، وفريق عن بعد، وكبح طارئ، وادعاء بلا نطاق |
| `map/use_cases_14.txt` | أربع عشرة بطاقة حالة استخدام | حالات عالية الأثر بجاهزية بيانات ضعيفة، وبيانات عن العمال |

## إعادة توليد الملفات

ملفات `files/` مولَّدة ببذرة ثابتة (205). النصوص في `_tools/texts.py`، والمولِّد:

```bash
uv run labs/_tools/prepare_files.py       # يكتب كل ملفات files/ من جديد
uv run labs/_tools/make_notebook.py       # يكتب routing_lab.ipynb
uv run labs/_tools/fetch_matrix.py        # مرة واحدة فقط: يطلب جدولَي المسافة والزمن من خادم OSRM العام
```

المحتوى نفسه في كل مرة؛ يتغير وقت الحفظ داخل ملفات xlsx فقط. الأعداد اليومية لشيكاغو في `_tools/source/`، والاستعلام
الذي أنتجها في `files/forecast/ATTRIBUTION.txt`.
